## About the Project

This project is a web application designed to manage a personal movie collection while discovering new films through the **TMDb (The Movie Database)** catalog.

### Key Features

- **Personal Collection**: Easily view, add, edit, and delete your favorite movies.
- **TMDb Discovery**:
  - Securely connect using your personal API key.
  - Browse the 20 most popular movies right now.
  - Search for any movie by its title.
  - Import movies directly from TMDb into your personal list with a single click 
- **Design & Performance**:
  - Clean, modern, and responsive interface that adapts to all screens.
  - Fast and smooth navigation without page reloading.
